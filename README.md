Clothing Rental Marketplace Platform

Project Overview

The Clothing Rental Marketplace Platform is a web application that allows users to rent clothes online for a specific period instead of buying them.

It connects customers and clothing owners in one platform.

Objectives

- Make clothing rental easy and affordable.
- Allow owners to rent out unused clothes.
- Provide easy booking and rental management.
- Manage users, clothes, bookings, and payments.

User Roles

Customer

- Register and login
- Browse clothes
- Search and filter
- Book clothes
- Make payments
- Give ratings and reviews

Clothing Owner

- Add clothes
- Set rental price
- Manage availability
- Manage rental bookings

Admin

- Manage users
- Manage clothes
- Manage bookings
- Manage payments and reviews

Main Features

- User Registration and Login
- Clothing Listing
- Search and Filter
- Rental Booking
- Payment Management
- Booking History
- Reviews and Ratings
- Admin Management

Technology Stack

- Frontend: React.js
- Backend: Java Spring Boot
- Database: MySQL
- Authentication: Spring Security + JWT
- Testing: JUnit
- API: REST API
- Version Control: Git & GitHub
- CI/CD: GitHub Actions
